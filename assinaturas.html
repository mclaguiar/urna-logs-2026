Autenticidade do pacote da urna — Eleições 2026

hw = FileAttachment("data/hw_cadeia.csv").csv({typed: true})
cob = FileAttachment("data/hw_cobertura.csv").csv({typed: true})
fmt = (n) => (n == null || n === "" || Number.isNaN(+n) ? "—" : Math.round(+n).toLocaleString("pt-BR"))
pct = (num, den) => den ? (100 * num / den).toLocaleString("pt-BR", {minimumFractionDigits: 1, maximumFractionDigits: 1}) + "%" : "—"
nomeUf = (uf) => uf === "ZZ" ? "Exterior" : uf
nSec = hw.reduce((s, d) => s + (+d.secoes || 0), 0)
nHash = hw.reduce((s, d) => s + (+d.hash_ok || 0), 0)
nHashFail = hw.reduce((s, d) => s + (+d.hash_falhou || 0), 0)
nFech = hw.reduce((s, d) => s + (+d.cadeia_fechada || 0), 0)
nFora = hw.reduce((s, d) => s + (+d.fora || 0), 0)

A chave usada na conferência é a do certificado publicado pela própria AC, no repositório indicado na Declaração de Práticas de Certificação (DPC-PC-ACURNA, seções 2.1 e 6.1.4). O arquivo é acurna.crt. O identificador da chave, cdaaf4b29701b3f0deb2b54258594a6d34ada48a, é o mesmo que as urnas UE2013 e UE2015 gravam no .vsc. Três certificados de Alagoas, modelos 2015, fecharam a assinatura com essa chave. A página do TSE sobre assinatura digital e lacração publica os resumos dos sistemas e o programa de verificação, e não este certificado.

Como a cadeia fecha

UE2020 e UE2022 · Ed521 · AC embutida no código

✓ hashbu, rdv e log
✓ .vsco hash gravado
✓ assinaturaEd521 com a chave do certificado
✓ certificado da urnaconferido com a AC UE2020 ou UE2022
✓ ACtodos os elos verificados

UE2013 e UE2015 · ECDSA P-521 · AC URNA publicada

✓ hashbu, rdv e log
✓ .vsco hash gravado
✓ assinaturaECDSA com a chave do certificado
✓ certificado da urnaassinatura confere com a AC publicada
✓ AC, certificado vencidoválido até 18/07/2026, antes da eleição. A conta não usa a data.

Seção cujo relatório ainda não foi refeito com esse certificado fica com o último elo pendente. Isso não é leitura de que o arquivo mudou.

Cadeia aberta é a seção UE2013/UE2015 cujo relatório ainda não confrontou o certificado da urna com a chave pública da AC URNA publicada em acurna.tse.jus.br/crt/acurna.crt. É um limite da verificação, não indício de alteração. Esse certificado da AC venceu em 18/07/2026, antes da eleição; onde o relatório já o usa, a assinatura confere e a data fica de fora da conta.

Cobertura

ufs = [...new Set(cob.map(d => d.uf))].sort((a, b) => (a === "ZZ") - (b === "ZZ") || nomeUf(a).localeCompare(nomeUf(b), "pt"))
par = uf => ({
  a: cob.find(d => d.uf === uf && +d.turno === 1) || {secoes: 0},
  b: cob.find(d => d.uf === uf && +d.turno === 2) || {secoes: 0}
})
comDado = ufs.filter(uf => +par(uf).a.secoes || +par(uf).b.secoes)
semDado = ufs.filter(uf => !comDado.includes(uf))
maxSec = Math.max(1, ...comDado.flatMap(uf => [+par(uf).a.secoes || 0, +par(uf).b.secoes || 0]))
html`<p class="legenda"><span style="color:#9ca3af">■</span> 1º turno, cinza · <span style="color:#374151">■</span> 2º turno, grafite. O número na barra é a quantidade de seções verificadas.</p>
<div>${comDado.map(uf => {
  const {a, b} = par(uf)
  const w = (n) => Math.max(+n ? 8 : 0, 100 * (+n || 0) / maxSec)
  return html`<div class="cob-uf"><span>${nomeUf(uf)}</span><div class="trilha">
    ${+a.secoes ? html`<div class="barra t1" style="width:${w(a.secoes)}%" title="1º turno"></div><span>${fmt(a.secoes)}</span>` : ""}
    ${+b.secoes ? html`<div class="barra t2" style="width:${w(b.secoes)}%" title="2º turno"></div><span>${fmt(b.secoes)}</span>` : ""}
  </div></div>`
})}</div>
<p>Ainda sem relatório: ${semDado.length ? semDado.map(nomeUf).join(", ") : "nenhuma"}.</p>`
porTurno = (turno) => cob.filter(d => +d.turno === turno && +d.secoes > 0)
lista = (turno) => porTurno(turno).map(d => nomeUf(d.uf)).join(", ") || "nenhuma"
secTurno = (turno) => porTurno(turno).reduce((s, d) => s + (+d.secoes || 0), 0)
md`1º turno: ${fmt(porTurno(1).length)} de ${fmt(cob.filter(d => +d.turno === 1).length)} UFs, ${fmt(secTurno(1))} seções (${lista(1)}). 2º turno: ${fmt(porTurno(2).length)} de ${fmt(cob.filter(d => +d.turno === 2).length)} UFs, ${fmt(secTurno(2))} seções (${lista(2)}).`
linha = (d) => {
  const den = +d.secoes || 0
  const modelos = [
    ["UE2013", +d.n_ue2013 || 0],
    ["UE2015", +d.n_ue2015 || 0],
    ["UE2020", +d.n_ue2020 || 0],
    ["UE2022", +d.n_ue2022 || 0]
  ]
  return {
    uf: nomeUf(d.uf),
    turno: `${d.turno}º`,
    secoes: fmt(d.secoes),
    hashOk: fmt(d.hash_ok),
    hashFalhou: fmt(d.hash_falhou),
    fechada: pct(+d.cadeia_fechada || 0, den),
    aberta: pct(+d.cadeia_aberta || 0, den),
    ue2013: pct(modelos[0][1], den),
    ue2015: pct(modelos[1][1], den),
    ue2020: pct(modelos[2][1], den),
    ue2022: pct(modelos[3][1], den),
    fora: fmt(d.fora),
    verificador: d.verificador
  }
}
