Painel 1º × 2º turno

Migração agregada, abstenção e indicador sem digital — Eleições 2026

Auditoria da cadeia pública (RDV ↔︎ BU ↔︎ CSV oficial), com foco em achados justificáveis seção a seção.

Hierarquia de evidência

Nível Significado
A Inconsistência documental (RDV≠BU, BU≠oficial, seção só num turno)
B Anomalia operacional (confluência de extremos na mesma seção, na UF)
C Contexto ecológico / flag isolada / taxas médias

Detalhe e limiares: Método. Concordância RDV≡BU≡CSV = consistência entre arquivos públicos na chave — não prova hardware.

2. Onde olhar (risco: sem digital × mudança)

Mede: seções com % sem digital (1º) alto e Δ margem (2º−1º) extremo na própria UF. Anomalia aqui = ponto nos extremos da distribuição da UF (flags pré-registradas), não veredito causal.

Sem digital = biografia + sem biometria no BU — indicador operacional; ganha força descritiva se coincidir com Δ atípico.

Mede: momento da habilitação no log (não voto em candidato), em horário de Brasília (ZZ = hora local do posto).

aggPorBrt = (subset, turno) => {
  const m = new Map(d3.range(24).map(h => [h, {hora: h, n: 0, turno, after: h >= 17}]));
  for (const d of subset) {
    if (+d.turno !== turno) continue;
    const h = +d.hora_brasilia;
    if (!m.has(h)) continue;
    m.get(h).n += +d.habilitacoes;
  }
  return [...m.values()].sort((a, b) => a.hora - b.hora);
}
baseHoras = ufHora === "BR"
  ? horas.filter(d => d.uf !== "ZZ")
  : horas.filter(d => d.uf === ufHora)
serie1 = aggPorBrt(baseHoras, 1)
serie2 = aggPorBrt(baseHoras, 2)
eixoLabel = ufHora === "ZZ" ? "Hora local (exterior)" : "Hora de Brasilia"
tot1 = d3.sum(serie1, d => d.n)
tot2 = d3.sum(serie2, d => d.n)
apos1 = d3.sum(serie1.filter(d => d.after), d => d.n)
apos2 = d3.sum(serie2.filter(d => d.after), d => d.n)
yMax = Math.max(d3.max(serie1, d => d.n) || 0, d3.max(serie2, d => d.n) || 0)
yPad = yMax > 0 ? yMax * 1.08 : 1
metaUf = (() => {
  const pico = serie1.length
    ? serie1.reduce((a, b) => (a.n >= b.n ? a : b))
    : null;
  const r = ufHora === "BR" ? null : rows.find(d => d.uf === ufHora);
  return {
    escopo: ufHora === "BR" ? "Todos (BRT, sem ZZ)" : ufHora,
    pct_apos_17h_1t: tot1 ? +(100 * apos1 / tot1).toFixed(4) : null,
    pct_apos_17h_2t: tot2 ? +(100 * apos2 / tot2).toFixed(4) : null,
    hora_pico_1t: pico ? pico.hora : null,
    ref: ufHora === "ZZ" ? "hora local" : "Brasilia",
    status_2t: r ? r.status_2t : (nPronto ? "comparativo ativo" : "pendente"),

})()
