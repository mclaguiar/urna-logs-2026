Consulta por seção

Votos da seção — totais do boletim

Escolha o estado, a cidade, a zona e a seção. Em zona e em seção, Todos soma o conjunto.

NotaComo ler

Os números de votos são os do boletim de urna, cargo presidente. O endereço da página guarda a seleção (?uf=&mun=&zona=&secao=), para compartilhar o link.

Numa seção, branco e nulo aparecem separados. Em zona ou cidade, ficam somados. Eliminados no 1º turno ficam numa linha que abre os candidatos.

A seção não tem matriz de migração. O 2º turno esperado aplica a matriz da cidade (ou a do estado, se a cidade não tiver a própria) aos votos do 1º turno deste conjunto. O resíduo é esse esperado menos o observado. O percentil de extremo da UF, em urna_logs.thresholds, mede |Δ margem| do boletim dentro da UF. Não mede esse resíduo. A linha de Lula ou de Flávio fica em destaque quando o resíduo de Brown e Payne passa de 5% do observado naquele destino.

A curva hora a hora é a da UF. O arquivo da seção guarda a fatia de habilitações após as 17h, não as 24 horas.

acumula = (spec, dest, turno) => {
  if (!spec) return
  for (const part of String(spec).split("|").filter(Boolean)) {
    const [cod, qtd] = part.split("=")
    const n = +qtd || 0
    if (cod === "13") dest["13"] += n
    else if (cod === "22") dest["22"] += n
    else if (cod === "95") dest.branco += n
    else if (cod === "96") dest.nulo += n
    else if (turno === 1) dest.eliminados += n
  }
}
margemDe = (row) => {
  const o = vazioO()
  const d = vazioD()
  acumula(row.t1, o, 1)
  acumula(row.t2, d, 2)
  o.abstencao = row.a1 || 0
  d.abstencao = row.a2 || 0
  return {o, d}
}
somaMargens = (rows) => {
  const o = vazioO()
  const d = vazioD()
  for (const row of rows) {
    const m = margemDe(row)

    for (const k of DESTINOS) d[k] += m.d[k]
  }
  return {o, d}
}
